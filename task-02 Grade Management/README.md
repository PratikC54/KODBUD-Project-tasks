# Task 02 – STUDENT GRADE MANAGEMENT SYSTEM

## Objective
A student grade management system using a console-based Java program.

## Features
- input student name and marks
- calculate average marks
- derive grade
- Exit system

- Loops
- Arrays
- Classes
- Conditional statements
- Methods
- Scanner input

## Goal
Goal: Learn classes, arrays, and basic logic.
