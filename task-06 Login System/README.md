# Task 06 – Login system

## Objective
Simulate a simple login system operations using a console-based Java program.

## Features
- Create a user (signup feature)
- Validate a user (signing feature)
- Store the user credential
- Verify the credential and ensure no vulnerability will happen

## Concepts Used
- Loops
- Conditional statements
- Methods
- Scanner input

## How to Run
```bash
javac LoginSystem.java
java LoginSystem
