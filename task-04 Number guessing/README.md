# Task 04 – Number Guessing Game

## Objective
Simulate basic ATM operations using a console-based Java program.

## Features
- Generate a random number between 1 and 100
- Ask user to guess until guessed correctly
- Proper guide to guess 
- Count the number of tries

## Concepts Used
- Loops
- Conditional statements
- Methods
- Scanner input
- Random class

## How to Run
```bash
javac NumberGuessing.java
java NumberGuessing
